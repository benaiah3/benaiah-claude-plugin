# Benaiah plugin icons

These are the exact light and dark PNG assets used by the ChatGPT V2 directory and composer icons, verified against the OpenAI portal on 26 September 2026.

The SVG embeds both original PNG files without altering their pixels. Its default is the black face on a white background. When the host supplies a dark colour scheme, it displays the white face on a black background. A host that strips SVG styles, rasterises the file, or does not communicate its theme may show the default image; a separate dark icon setting is not currently exposed in the Claude plugin listing.

Original PNG SHA-256 hashes:

- Light: 3b97ffdb7d3e1bdcbf19b4cf49de0f63c517f5b0e4493c23e9a390c3fbfbfb1a
- Dark: fce54ec7dd0c491d5cf617ec069ad743159e0272824a539d668ba43bba52243e

The two original PNG files are retained for hosts that support separate theme icons. The SVG has a 512 by 512 viewport and uses the original 256 by 256 images, matching the existing artwork rather than redrawing it.
