# Benaiah plugin icons

These are the exact light and dark PNG assets used by the ChatGPT V2 directory and composer icons, verified against the OpenAI portal on 26 September 2026. Both images are copied byte for byte, without redrawing or resizing.

The Claude directory exposes one icon field. It rejects SVG styles, including colour-scheme media queries, and does not expose a separate dark icon field. Its icon therefore uses the light PNG with the original white background intact, keeping the black face visible in either host theme. The matching white face on black PNG is retained for surfaces that support a separate dark icon.
